# Models

This repository keeps a small curated set of demonstration meshes under `models/`.

Included assets:

- `David.stl` — large, high-triangle-count mesh used by the single-mesh and spatial-reuse examples
- `Eiffel_Tower.stl` — medium-scale demonstration mesh used in the viewer gallery and alternative workflows
- `C12.STL` — outer geometry used by the shared-grid multi-mesh example
- `2,5 mm cut.STL` — inner geometry used by the shared-grid multi-mesh example

These files are intended for viewer, voxelization, slice-plotting, BVH, and octree demonstrations.
